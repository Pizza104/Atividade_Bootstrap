# exercício de Bootstrap

Este é um projeto para praticar componentes e utilitários do **Bootstrap 4.6.2**. O nome e o conteúdo são demonstrativos ou seja caso você que esteja lendo isso queira testar não irá funcionar a validação de dados e ou contato por favor, caso queira entrar em contato vá para o meu repositório onde há meu currículo: personalize a identidade, os textos e os canais de contato antes de publicar como um negócio real.

## Páginas

 `index.html` navegação responsiva, chamada principal, cards, acordeão e chamadas para ação.
 `sobre.html` conteúdo semântico, cards de valores e linha do tempo.
 `servicos.html` cards, badges, listas, âncoras e acordeão de etapas.
 `contato.html` formulário com validação no navegador e feedback de demonstração.

## Como abrir

Abra o link do vercel que está ao lado do repositorio escrito bootstrap e clique para acessar.


## Formulário

O formulário de contato **não envia nem armazena dados** ele só valida os campos no navegador e exibe uma mensagem informativa.
